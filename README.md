# GeoBusca CEP

Atividade guiada — Frameworks Web I (Unilavras), aula 05.

App em React + Vite que busca um endereço pelo CEP (ViaCEP), converte em coordenadas (OpenCage), mostra no mapa (react-leaflet) e salva favoritos no localStorage. UI com Material-UI e styled-components.

## Como rodar

```bash
npm install
cp .env.example .env   # depois cole sua chave do OpenCage no .env
npm run dev
```
